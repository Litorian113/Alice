# Deploying the relay on Coolify (bob-relay.zeigma.com)

**Status:** live since 27 September 2026 and verified with `backend/tools/check-relay.js --hold 130`:
health check, web page, pairing over `wss://`, forwarding both ways, wrong-secret rejection, and
WebSockets idle for 130 s through Cloudflare. Voice is off until `ASSEMBLYAI_API_KEY` is set (below).

The relay is one small Node container. Coolify builds it from `backend/relay/Dockerfile`, and
its Traefik proxy terminates TLS. Cloudflare sits in front (the DNS record is already
proxied and reaches Coolify's Traefik).

## 1. Create the resource

Coolify → Project → **+ New** → **Public Repository** (the repo is public; use **Private Repository
(GitHub App)** otherwise) → repository URL + branch `main`, then:

| Setting | Value |
| --- | --- |
| Build pack | **Dockerfile** |
| Base directory | `/backend/relay` |
| Dockerfile location | `/Dockerfile` (relative to the base directory) |
| Ports exposes | `8787` |
| Domains | `https://bob-relay.zeigma.com` |
| Health check | Dockerfile defines one (`/healthz`). Or set it in Coolify: path `/healthz`, port `8787` |

**Environment variables** (Coolify → Environment Variables):

| Var | Value | Why |
| --- | --- | --- |
| `PUBLIC_URL` | `https://bob-relay.zeigma.com` | Enables ntfy answer buttons + click-to-open |
| `PUSH_DETAILS` | `1` (or `0`) | `0` keeps card text off ntfy.sh |
| `ASSEMBLYAI_API_KEY` | your AssemblyAI key | Enables voice: the relay issues short-lived transcription tokens to Alice. Without it, the phone reports voice as unavailable |
| `ASSEMBLYAI_REGION` | `eu` (default) | Optional |
| `ROOM_GRACE_S` | `30` | Optional |

Don't set `PORT`. The container listens on 8787, which is what "Ports exposes" points Traefik at.

Deploy. The relay is stateless (rooms are in memory), so redeploys just make clients
reconnect: the MCP server and the phone both retry automatically, and open cards are re-sent.

## 2. Cloudflare

- **SSL/TLS mode: Full or Full (strict).** Not *Flexible*: Coolify redirects HTTP → HTTPS,
  and with Flexible that becomes a redirect loop. Full (strict) needs a valid origin cert.
  Coolify's Let's Encrypt cert works once issued. If issuance fails behind the proxy, use
  **Full**, or a Cloudflare Origin Certificate.
- **WebSockets:** on by default on all plans (Network → WebSockets).
- **Idle timeout:** Cloudflare closes idle WebSockets after 100 s. The relay pings every
  30 s, so connections stay up. `backend/tools/check-relay.js --hold 130` verifies this.
- Only one replica: rooms live in memory, so don't scale horizontally.

## 3. Verify

```sh
cd backend
node tools/check-relay.js https://bob-relay.zeigma.com            # ~2 s
node tools/check-relay.js https://bob-relay.zeigma.com --hold 130 # proves idle sockets survive Cloudflare
```

Expected: all ✔. Then open https://bob-relay.zeigma.com on the phone. The dev phone page
should load and show "Pair".

## 4. Point Bob at it

`.bob/mcp.json` (repository root) and the demo workspace generated by `demo/setup.sh` already use:

```json
"RELAY_URL": "wss://bob-relay.zeigma.com",
"COMPANION_QR": "app"
```

`COMPANION_QR=app` puts a `bobcompanion://pair?…` link in the QR code, which opens Alice directly.
With `web` the QR opens `https://bob-relay.zeigma.com/#s=…&k=…`, the browser phone page, which is
useful for testing without the app.

For local development against a local relay, set `RELAY_URL` to `ws://localhost:8787`
(tests and `fake-bob` default to local, or use their `RELAY_URL` env).

## Troubleshooting

| Symptom | Cause |
| --- | --- |
| `503 no available server` | Traefik has no route: the app isn't running/healthy, or the domain isn't set on the resource |
| `ERR_TOO_MANY_REDIRECTS` | Cloudflare SSL mode is Flexible → switch to Full |
| WebSocket 101 never happens, HTTP works | Cloudflare WebSockets disabled, or a proxy rule strips `Upgrade` |
| Phone disconnects every ~100 s | Pings not getting through; check that the relay logs show no errors and it's a single replica |
| MCP stderr: `relay connect failed` | Wrong `RELAY_URL` (must be `wss://`, no path) |
